# Cryptography-Project-NCI

# Setup

## Windows

1. Create the virtual environment to store the python libraries.
2. Access the (venv) command line in order to use pip install.
3. After installing all python libaries, exit the (venv) command line.

```
python3 -m venv venv 
.\venv\Scripts\Activate.ps1
pip install -e .[dev]
deactivate
```

## To Run

1. Access the (venv) command line
2. Execute "python secure_app/main.py
